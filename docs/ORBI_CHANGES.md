# Orbi 改造记录

维护者：[李俊祎 / 17lijunyi](https://github.com/17lijunyi)

改造日期：2026-09-30 至 2026-10-01。

Orbi 基于 [egoist/lorca](https://github.com/egoist/lorca) 的 `9e5624fb8147d773f62822d58edcc7d6cc2954f2` 继续开发，保留上游提交历史和 GNU GPL v3 许可证。这份记录说明本版本的具体改动。

## 桌面体验

- AppKit 悬浮玻璃工作区，包含独立导航、智能体卡片与消息输入栏。
- 智能体资料库支持搜索、角色卡片、设备状态与聊天入口。
- 聊天、设置、市场和弹窗采用统一材质与视觉层级。
- 中文化内置角色、设备名称、示例会话、模拟回复和市场介绍。
- 应用显示名为 Orbi，使用铺满画布的星环图标。

## 开发与分发

- Command Line Tools 环境下可打包 Markdown 静态库和 UniFFI 头文件。
- 图标打包脚本从同一原图生成十种 macOS 图标尺寸。
- Orbi 构建通过显式配置的更新源和公钥启用 Sparkle。
- README 提供源码构建、演示模式、验证状态与项目来源说明。

## 技术来源

本地 Rust 服务、智能体循环、模型服务商适配、密钥身份、端到端加密配对与同步、加密凭证、插件和手机客户端来自 Lorca 的开源实现。Orbi 继续使用这套机制。

完整代码以 [GPL-3.0-only](../LICENSE) 开源。Orbi 的产品设计与界面改造由李俊祎主导，代码实现和图标制作使用 AI 工具辅助。
