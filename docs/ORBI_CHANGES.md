# Orbi 产品与功能

维护者：[李俊祎 / 17lijunyi](https://github.com/17lijunyi)

更新日期：2026-10-06

Orbi 是李俊祎个人打造并持续维护的 macOS AI 工作台，提供智能体协作、中文交互、毛绒星球 DIY、个性化窗口背景与悬浮聊天体验。本文说明当前提供的桌面体验及相应实现。

## 原生桌面工作台

Orbi 的 macOS 应用使用 AppKit。主窗口由操作胶囊、圆角工作区和独立消息输入栏组成；主页侧栏负责资料库、最近聊天、模型服务与市场导航，底部提供设备、设置和搜索。智能体资料库使用角色卡片，提供搜索、筛选、设备信息和聊天入口。聊天、设置、市场与弹窗共用视觉层级。

胶囊依次提供「待办、浮窗、创建群聊、创建」四个按键，创建群聊位于浮窗下面，打开侧栏中的成员选择。按键采用细线图标、小号文字与柔和选中背景。待办从胶囊打开，便笺从文件菜单打开，各自使用独立可拖动窗口，支持置顶与关闭；便笺自动保存并可转为待办，待办支持添加、完成、删除和清除已完成项。内容保存在本机应用偏好中，按账户身份分别保存，重启后恢复。

浮窗使用独立的原生聊天视图与输入栏，和主窗口共享同一段对话、消息流、附件、语音与智能体提及功能。小窗支持置顶，主窗口最小化后仍可聊天；断开连接时停止发送并保留草稿。便笺与聊天小窗可以同时打开。重复点击便笺、待办或浮窗入口会将已打开的小窗置前并聚焦，关闭使用各小窗的关闭按钮。设置侧栏的返回按钮使用主文字色，并提供更大的点击区域；头像、成员行、市场条目和聊天快捷项接受非激活窗口中的首次点击。底部毛绒星球的「创建」打开现有新建智能体表单与形象选择。文件菜单提供群聊与设备配对；群聊打开队友抽屉，保留搜索、多选和草稿。关闭、最小化与缩放使用工作区顶部的原生窗口按钮。

应用显示名、菜单与欢迎流程使用 Orbi。界面提供中文菜单、设置、内置角色、设备文案、示例会话与市场介绍，并保留应用语言切换。形象编辑器和窗口背景选项使用中文文案。

## 毛绒星球形象

默认形象为粉色毛绒星球：星光眼、斜向星环与右上方小卫星，PNG 使用透明背景。资料库和聊天头像按完整轮廓显示。

原生形象编辑器包含 12 款预设：星光粉、粉色绅士、蓝色画家、柠檬学者、紫色墨镜、青柠好奇心、珊瑚魔术师、天空音乐家、薄荷小王子、兰紫绒球、奶油小呆毛和薰衣草漫步。

编辑器分别提供「形象」「形状」「眼睛」「眼镜」「配饰」页。形状包含圆形、三角形、胶囊、小熊、云朵、爱心、蝴蝶、嫩芽、花朵、卵石与菱形，共 11 种轮廓，保留毛绒材质、斜向星环和小卫星。每张形象卡片拥有独立随机分配的形状，并在本次编辑期间保持稳定。切换形状只改变当前预览，选择卡片则采用该卡片的完整形状、配色与部件。

用户可以从预设开始，组合眼睛、眼镜与配饰，分别调整星球、眼镜、配饰的颜色，输入 HEX 色值，随机搭配，或导入图片。随机搭配为各卡片重新分配独立形状，同时改变当前预览的形状、配色与部件。预览在编辑器内更新，保存才应用，取消保留已有选择。毛绒质感由透明分层素材合成，配色调整保留材质明暗。

新建智能体的外观栏提供 8 款不同形状和配色的随机形象，支持「换一组」。候选在填写表单和点击选择时保持稳定；创建前将选中的配置渲染成 512 px PNG，通过同一条 `bots.create` 请求连同资料保存，头像作为加密附件同步。

同一个编辑器有两处入口，保存范围不同：

| 入口 | 应用范围 | 保存方式 |
| --- | --- | --- |
| 设置 → 通用 → App 图标 → 预设与 DIY | 当前 Mac 上的 Orbi App 图标及应用内图标预览 | 本地偏好保存配置，导入图片保存在应用支持目录；启动时恢复 |
| 智能体资料面板头像，或资料库卡片右键菜单 | 该智能体的卡片、聊天与资料头像 | 写入 512 px PNG，经 `bots.update.avatar` 保存为加密附件并同步到已配对设备 |

智能体头像的 v2 文件名记录形状、颜色与部件选择，使配对 Mac 可以恢复可编辑的组合。v1 文件名及缺少形状字段的本地图标配置按圆形恢复。App 图标使用 `NSApp.applicationIconImage` 更新运行中的图标；打包图标来自 `macos/Resources/Orbi.png` 和 `Orbi.icns`。开发版与正式版分别保存各自的本地图标偏好。

## 七款窗口背景

设置 → 通用 → 窗口背景提供星雾、深湾、青苔、岩茶、暮莓、纯白与纯黑。前五款为三色对角渐变，后两款为纯色。设置页以 4+3 两行微型窗口预览展示选项，支持点击、方向键、空格与辅助功能，也可通过设置搜索定位。

背景选择立即应用到工作区、导航、消息输入栏、弹窗与欢迎界面，并写入当前应用的 UserDefaults。默认背景为星雾；纯白使用 Aqua，其余使用 Dark Aqua，文字、分隔线和聊天气泡同步调整对比度。重启恢复上次选择。

窗口背景与 App 图标、智能体头像分别设置。窗口表面绘制所选配色，悬浮表面之间的间隙透出桌面。

相关实现为 `Design/WindowBackground.swift`、`Design/SpatialChrome.swift`、`Design/Theme.swift` 与 `Settings/WindowBackgroundPicker.swift`，路径均相对于 `macos/Sources/Lorca/`。

## 本地运行与加密同步

Orbi 的 AppKit 界面连接本机 Rust CLI，CLI 随应用打包并由应用按需启动，负责智能体循环、模型服务商适配、工具与插件、例行任务、群聊协作和任务交接。

身份是本地密钥对。配对设备通过端到端加密中继同步账户数据；模型服务商凭证属于账户，作为账户密钥加密的 `credentials` 数据同步。智能体头像以加密文件附件同步，App 图标与窗口背景保存在各设备本地。完整机制见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

## 构建与验证

`bun run build --debug` 构建 Orbi Dev，`bun run build` 构建 Orbi。构建脚本在 Command Line Tools 环境下打包 Markdown 静态库与 UniFFI 头文件，并将毛绒分层素材与图标放入应用包。`scripts/app-icon.ts` 从默认 PNG 生成十种标准 macOS 图标规格。

截至本文更新，开发版在 Apple Silicon Mac 上完成构建；毛绒编辑器与窗口背景使用原生界面检查。背景选择器另外通过独立 AppKit 布局检查，覆盖 560 px 与 1000 px 宽窗口，验证七个选项的布局及窗口宽度保持。

形状配置检查覆盖 486 个 v1 组合与 5346 个 v2 文件名、JSON 往返组合，旧图标偏好保留原配色与部件。独立应用偏好验证爱心图标保存及重启恢复，不写入用户的设置。隐藏 AppKit 窗口检查五页均保持 780 × 500，标签、选项与色板不重叠；随机与保存检查验证独立候选、选中配置、单独修改形状及取消路径。

`bun run test:workbench` 使用独立临时偏好域，验证中文便笺、待办标识与完成状态重启恢复，账户切换及退出隔离，以及删除和清除已完成项的持久保存。`bun run test:mac-startup` 检查启动流程；`bun run l10n` 检查 macOS 与手机端本地化文案及占位符。原生界面检查在独立演示账户中进行，不写入用户聊天或凭证。Swift XCTest 使用 `swift test --package-path macos`，需要提供 XCTest 的完整 Xcode。源码构建与检查不替代发布包的签名、公证和分发验证。

发布构建通过显式配置的 `FEED_URL`、`SPARKLE_PUBLIC_KEY` 启用 Sparkle 更新；发布步骤见 [macOS 发布说明](releasing-mac.md)。
